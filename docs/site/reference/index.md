# Reference

## Public API

| item | what it is |
|---|---|
| `is_whitespace`, `is_alpha`, `is_alphanumeric`, `is_numeric` | the predicates, named semantically |
| `to_upper`, `to_lower` | character transforms |
| `at(s, i)` | the i-th **character** — indices are never byte offsets |
| `length`, `slice`, `concat` | sequence operations |
| `code_point` / `from_code_point` | the only scalar-value access; backends may bound the range |
| characters | represented as 1-char strings — handl has no separate char type |

## Crate

| crate | role |
|---|---|
| `char` | contract (axioms) — pure handl |

## Build and test

```bash
cargo build     # sibling [patch] tables resolve deps from ../<repo>
cargo test      # hnl test (pure-handl contract; laws are exercised by the backends)
```

Dependencies are git deps on `branch = "main"`; locally the `[patch]` tables
point at sibling checkouts (regenerated by `host/scripts/dev-link.sh`).
